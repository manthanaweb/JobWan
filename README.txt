JOBWAN 4.3 — Simulated HR login gate
======================================

วิธีใช้
1. แตกไฟล์ ZIP
2. เปิด index.html ด้วย Chrome / Edge / Safari
3. ไปหน้า "ตั้งค่า" > กรอกรหัสองค์กรอะไรก็ได้ (โหมดสาธิต) > กดปุ่ม "🔐 เข้าสู่ระบบ HR (จำลอง)"
4. กรอกอีเมล/รหัสผ่านอะไรก็ได้ (ยังไม่ตรวจสอบจริง) > เข้าสู่ระบบ > เข้าสู่แดชบอร์ด HR (จำลอง)

สิ่งที่เพิ่มในรอบนี้
ก่อนหน้านี้พนักงานคนไหนก็กดปุ่มเดียวเข้าแดชบอร์ด HR ได้เลย ซึ่งไม่ได้สะท้อนว่าในระบบจริง HR
ต้องมีการยืนยันตัวตนแยกต่างหากจากรหัสที่พนักงานใช้เข้าร่วมองค์กร รอบนี้เพิ่มหน้า "เข้าสู่ระบบ HR"
คั่นกลางไว้ก่อนเข้าแดชบอร์ดเสมอ:

- กรอกอีเมล + รหัสผ่าน (จำลอง ยังไม่เชื่อมเซิร์ฟเวอร์จริง กรอกอะไรก็ผ่าน) แทนการกดปุ่มเดียวเข้าเลย
- แดชบอร์ดแสดง "เข้าสู่ระบบในฐานะ [อีเมลที่กรอก]" ที่มุมบนเสมอ
- ปุ่ม "ออกจากระบบ HR" ที่ทางออกจะล้างสถานะ login จริง ๆ (ไม่ใช่แค่กลับไปหน้าอื่น) ครั้งหน้าต้อง
  ล็อกอินใหม่ทุกครั้งที่กลับเข้ามาดู
- ออกจากองค์กร หรือลบข้อมูลทั้งหมด จะล้างสถานะ login ของ HR ไปด้วยเสมอ
- สถานะ login ของ HR ไม่ถูกบันทึกลง localStorage (เป็น session ชั่วคราวในหน่วยความจำ) ปิดเบราว์เซอร์
  แล้วเปิดใหม่ต้องล็อกอินใหม่ จำลองพฤติกรรม session ที่หมดอายุแบบระบบจริง

หมายเหตุสำคัญ
- นี่คือ "การจำลอง" การยืนยันตัวตนเท่านั้น ไม่ได้ตรวจสอบรหัสผ่านกับเซิร์ฟเวอร์จริง ไม่มีการเข้ารหัส
  ไม่มี rate limiting ไม่มีการกู้คืนรหัสผ่าน ฯลฯ ระบบจริงต้องมี backend + ระบบยืนยันตัวตนที่ปลอดภัย
  (เช่น SSO ขององค์กร, OAuth, หรือระบบรหัสผ่านที่เข้ารหัสอย่างถูกต้อง)
- ข้อมูลสมาชิกทีมในแดชบอร์ดยังเป็นข้อมูลสุ่มจำลองเหมือนเดิม
- Prototype นี้ยังไม่มีระบบสมาชิกหรือ cloud database ข้อมูลทั้งหมดอยู่ใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น
- ก่อนเปิดใช้จริงควรเพิ่ม Privacy Policy, Consent, ระบบรักษาความปลอดภัย และช่องทางช่วยเหลือสุขภาพจิตที่เป็นทางการ
