JOBWAN 3.3 — Shutdown ritual merged into Diary (one record per day)
=====================================================================

วิธีใช้
1. แตกไฟล์ ZIP
2. เปิด index.html ด้วย Chrome / Edge / Safari
3. ข้อมูลถูกเก็บใน localStorage ของเบราว์เซอร์นี้เท่านั้น

สิ่งที่เปลี่ยนในรอบนี้: เลิกถามซ้ำ "เรื่องที่ค้างใจ" และ "สิ่งที่ทำสำเร็จ" สองที่
- เดิม: หน้า "ปิดวันทำงาน" เก็บ task/win/plan ไว้ใน state.journal (array แยก) ส่วนหน้า "ไดอารี่"
  เก็บ pending/win ไว้ใน state.diary[date] (คนละที่เก็บ) ทำให้ผู้ใช้อาจถูกถามเรื่องเดียวกันสองรอบ
  และข้อมูลสองฝั่งไม่เชื่อมกัน
- ตอนนี้: ทุกอย่างเขียนลง state.diary[date] ที่เดียว — "ปิดวันทำงาน" กลายเป็นวิซาร์ดแบบมีขั้นตอน
  (guided) สำหรับกรอกฟิลด์ pending/win/plan ของวันนี้ ส่วน "ไดอารี่" เป็นหน้าที่เห็น/แก้ไขฟิลด์เดียวกัน
  แบบเต็มรูปแบบ (ตอนนี้มีช่อง "แผนสำหรับวันถัดไป" เพิ่มเข้ามาในฟอร์มไดอารี่ด้วย)
- เปิดหน้าไหนก่อนก็ได้ ข้อมูลจะ sync กันเสมอ: เขียนใน Diary ก่อนแล้วค่อยกด "ปิดวันทำงาน" ทีหลัง
  ขั้นตอนที่ 1/2 จะดึงสิ่งที่เขียนไว้แล้วมาให้แก้ไขต่อ ไม่ต้องพิมพ์ใหม่
- state.journal ถูกถอดออกทั้งหมด (รวมทุกจุดที่เคยอ้างอิง: หน้าแรก, หน้าตั้งค่า, export JSON,
  สรุปสำหรับที่ปรึกษา, ตัวเช็กการแจ้งเตือน)

ลูกเล่นที่เพิ่มเข้ามา
- อนิเมชัน fade+slide เบา ๆ ทุกครั้งที่เปลี่ยนขั้นตอนในพิธีกรรมปิดวันทำงาน
- หน้าจอ "จบงานแล้ว" มีตัวนับ "ปิดวันทำงานต่อเนื่องมาแล้ว X วัน" (แบบให้กำลังใจ ไม่ตัดสินถ้าขาดช่วง)
- ปุ่มเลือกอารมณ์ในไดอารี่/เช็กใจ มีอนิเมชัน bounce ตอนเลือก
- ช่องวันที่ในปฏิทินไดอารี่มี hover/selected transition นุ่มขึ้น
- Memory Jar มีอนิเมชัน pop ตอนสุ่มเปิดความทรงจำใหม่ทุกครั้ง

ฟีเจอร์ทั้งหมด: Home, จบวันทำงาน (วิซาร์ด 3 ขั้น เขียนลงไดอารี่), ไดอารี่ (ปฏิทิน+Mind Report+Memory Jar+
Mind Check Point+แผนวันถัดไป), ปล่อยวาง (Release Room), พื้นที่ปล่อยใจ (ชุมชนนิรนาม), เช็กใจ (ทางลัดบันทึก
อารมณ์ลงไดอารี่), ค้นหาความช่วยเหลือ, บทความ, ตั้งค่า/ความเป็นส่วนตัว, PWA ออฟไลน์

หมายเหตุ
- Prototype นี้ยังไม่มีระบบสมาชิกหรือ cloud database ข้อมูลทั้งหมดอยู่ใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น
- Mind Check Point และ Mind Report เป็น wellness signal จากข้อมูลที่ผู้ใช้บันทึกเอง ไม่ใช่การวินิจฉัยโรค
- ก่อนเปิดใช้จริงควรเพิ่ม Privacy Policy, Consent, ระบบรักษาความปลอดภัย และช่องทางช่วยเหลือสุขภาพจิตที่เป็นทางการ
