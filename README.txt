JOBWAN 4.0 — Diary absorbs Shutdown, Community absorbs Release Room
=====================================================================

วิธีใช้
1. แตกไฟล์ ZIP
2. เปิด index.html ด้วย Chrome / Edge / Safari
3. ข้อมูลถูกเก็บใน localStorage ของเบราว์เซอร์นี้เท่านั้น

สิ่งที่เปลี่ยนในรอบนี้: ลดฟีเจอร์ที่ซ้อนกันจาก 9 เมนูเหลือ 7 เมนู
ก่อนหน้านี้ "ปิดวันทำงาน" กับ "ไดอารี่" เขียนลงข้อมูลเดียวกันแล้ว แต่ยังเป็นคนละหน้าคนละปุ่มในเมนู
ทำให้ดูเหมือนสองฟีเจอร์ที่ซ้ำกัน ส่วน "ปล่อยวาง" (ส่วนตัว) กับ "พื้นที่ปล่อยใจ" (ชุมชน) ก็ใช้ชื่อ
คล้ายกันจนสับสนว่าต่างกันอย่างไร รอบนี้จึงยุบรวมเป็นโหมดภายในหน้าเดียวกัน:

1) ไดอารี่ & จบวัน (เมนูเดียว แทนที่ "ปิดวันทำงาน" + "ไดอารี่")
   - ค่าเริ่มต้น: ฟอร์มเต็มรูปแบบของไดอารี่ (ปฏิทิน + mood + เรื่องราว + ค้างใจ + ทำสำเร็จ + แผนวันถัดไป)
   - ปุ่ม "☾ เริ่มพิธีกรรมปิดวันทำงาน" สลับไปโหมดวิซาร์ด 3 ขั้นตอนแบบเดิม (เขียนลงวันเดียวกัน)
   - มีลิงก์ "← กลับไปบันทึกแบบเต็ม" ให้สลับกลับได้ตลอด
   - วิซาร์ดใช้ได้กับ "วันนี้" เท่านั้น ถ้าเลือกวันอื่นในปฏิทินจะกลับไปโหมดฟอร์มเต็มอัตโนมัติ

2) พื้นที่ปล่อยใจ (เมนูเดียว แทนที่ "ปล่อยวาง" + "พื้นที่ปล่อยใจ")
   - แท็บ "🫂 แบ่งปันกับชุมชน" = โพสต์สาธารณะแบบไม่ระบุตัวตน (ของเดิม)
   - แท็บ "🕊 ปล่อยส่วนตัว" = พิธีกรรมเผา/ฉีก/ทะเล/หลุมดำ (ของเดิม ไม่มีใครเห็น)
   - ฟีเจอร์ใหม่ที่ได้จากการรวม: หลังปล่อยส่วนตัวเสร็จ (ถ้าข้อความไม่ได้มีสัญญาณเสี่ยงสูง) จะถามว่า
     "อยากแบ่งปันกับคนอื่นไหม" ถ้าเลือกแชร์ จะพาไปแท็บชุมชนพร้อมดึงข้อความมาเป็นร่าง ให้แก้ไขและ
     ยืนยันอีกครั้งก่อนโพสต์เสมอ (ไม่โพสต์อัตโนมัติ) ถ้าไม่อยากแชร์ก็ปิดได้เลย ไม่มีผลอะไร

เมนูที่เหลือ 7 อัน: Home, ไดอารี่ & จบวัน, พื้นที่ปล่อยใจ, เช็กใจ, ค้นหาความช่วยเหลือ, บทความ, ตั้งค่า
(เมนูด้านล่างบนมือถือ กลับมาเป็น 5 อันตามเดิม: Home, ไดอารี่, ปล่อยใจ, เช็กใจ, ช่วยเหลือ)

หมายเหตุ
- Prototype นี้ยังไม่มีระบบสมาชิกหรือ cloud database ข้อมูลทั้งหมดอยู่ใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น
- Mind Check Point และ Mind Report เป็น wellness signal จากข้อมูลที่ผู้ใช้บันทึกเอง ไม่ใช่การวินิจฉัยโรค
- ก่อนเปิดใช้จริงควรเพิ่ม Privacy Policy, Consent, ระบบรักษาความปลอดภัย และช่องทางช่วยเหลือสุขภาพจิตที่เป็นทางการ
