JOBWAN 5.3 — Removed the small k-anonymity slider demo + app-wide back button
================================================================================

สิ่งที่เปลี่ยนในรอบนี้

1) ตัดส่วน "ทดลองแนวคิด k-anonymity" (ปุ่มเลือก 2/3/5/8/12 คน) ออกจากแดชบอร์ด HR
   เพราะซ้ำซ้อนกับแดชบอร์ดเต็มรูปแบบ 1,000 คนที่อยู่ด้านล่างอยู่แล้ว ซึ่งโชว์การล็อกตามเกณฑ์ขั้นต่ำ
   5 คนในระดับแผนกจริง ๆ ชัดเจนกว่า — คงคำอธิบายหลักการ k-anonymity ไว้ในข้อความเตือนด้านบนแทน

2) เพิ่มปุ่ม "← ย้อนกลับ" ที่หัวข้อทุกหน้าในแอป (ไม่ใช่แค่หน้าใดหน้าหนึ่ง) ทำงานด้วยการจำประวัติ
   หน้าที่เคยเปิดไว้เป็นสแตก (เหมือนปุ่ม back ของเบราว์เซอร์ แต่เป็นของแอปเอง ไม่พึ่งปุ่ม back จริง)
   - กดจากเมนูด้านข้าง, การ์ดในหน้าแรก, หรือปุ่มต่าง ๆ ที่เปลี่ยนหน้า (เช่น "เริ่มพิธีกรรมปิดวันทำงาน",
     "เข้าสู่ระบบ HR") ล้วนถูกบันทึกไว้ในประวัติ กดย้อนกลับได้เสมอ
   - ปุ่มนี้จะไม่โผล่ในหน้าแรกสุดของแอป (ยังไม่มีที่ให้ย้อนกลับ) และจะไม่โผล่ระหว่างอยู่ในเซสชัน HR
     (เพราะหน้านั้นต้องออกผ่านปุ่ม "ออกจากระบบ HR" เท่านั้น ย้อนกลับเฉย ๆ จะถูกดึงกลับมาหน้าเดิม)
   - ลบข้อมูลทั้งหมดจะล้างประวัติการย้อนกลับไปด้วย เหมือนเปิดแอปใหม่

ฟีเจอร์อื่นทั้งหมดเหมือนเดิมทุกอย่าง

หมายเหตุสำคัญ
- Prototype นี้ยังไม่มีระบบสมาชิกหรือ cloud database ข้อมูลทั้งหมดอยู่ใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น
- ก่อนเปิดใช้จริงควรเพิ่ม Privacy Policy, Consent, ระบบรักษาความปลอดภัย และช่องทางช่วยเหลือสุขภาพจิตที่เป็นทางการ
