JOBWAN 5.0 — 1,000-employee org dashboard + new business model (฿59 one-time)
================================================================================

วิธีใช้
1. แตกไฟล์ ZIP แล้วเปิด index.html
2. เปิดแอปครั้งแรกจะเจอหน้า "ซื้อแบบรายบุคคล ฿59" ก่อนใช้งานได้ (กดซื้อ หรือกรอกรหัสองค์กรเพื่อใช้ฟรี)
3. ไปหน้าตั้งค่า > เข้าสู่ระบบ HR (จำลอง) เพื่อดูแดชบอร์ดองค์กร 1,000 คน

สิ่งที่เปลี่ยนในรอบนี้

1) โมเดลธุรกิจใหม่: รายบุคคลจ่ายครั้งเดียว ฿59 ใช้ฟรีตลอดไป / องค์กรจ่ายแบบ subscription ต่อที่นั่ง
   - เปิดแอปครั้งแรก (ยังไม่เคยซื้อ ยังไม่เคยเชื่อมองค์กร) จะเจอหน้าซื้อก่อนเข้าแอปได้เลยทุกหน้า
   - กด "ซื้อเลย ฿59 (จำลอง)" → ปลดล็อกแอปทั้งหมดถาวร (บันทึกไว้ในเครื่อง ไม่ต้องจ่ายซ้ำ)
   - หรือกรอก "รหัสองค์กร" ในหน้าเดียวกัน → ใช้งานฟรีทันทีโดยไม่ต้องจ่ายเอง (องค์กรจ่ายแทน)
   - หน้าตั้งค่าโชว์ "สถานะการเข้าถึงของคุณ" บอกชัดว่าปลดล็อกด้วยวิธีไหน
   - ลบข้อมูลทั้งหมด = รีเซ็ตกลับไปเจอหน้าซื้อใหม่ (เหมือนลงแอปใหม่)

2) แดชบอร์ด HR ขยายเป็นองค์กรขนาด 1,000 คน แบ่ง 7 แผนก (วิศวกรรม/เทคโนโลยี, ฝ่ายขาย, ปฏิบัติการ,
   การตลาด, การเงิน/บัญชี, ทรัพยากรบุคคล, บริการลูกค้า) แต่ละแผนกจำลองอัตราการเชื่อมบัญชี (40-75%)
   และสัดส่วนสุขภาพใจ 3 ระดับ (ดี/ปานกลาง/ควรดูแลเพิ่ม) แยกกัน
   - แผนกที่มีผู้เชื่อมบัญชีต่ำกว่า 5 คน จะถูกล็อกไม่ให้เห็นสัดส่วนสุขภาพใจ (ป้องกันระบุตัวบุคคลในแผนกเล็ก
     อย่างเช่น HR 35 คนที่อาจมีคนเชื่อมบัญชีแค่ไม่กี่คน) แม้ภาพรวมทั้งองค์กร 1,000 คนจะไม่ติดเกณฑ์นี้เลยก็ตาม
   - ปุ่ม "🔀 สุ่มข้อมูลใหม่" เพื่อดูการกระจายตัวแบบอื่น ๆ
   - ข้อความเตือนชัดเจนตลอดว่า "ไม่แสดงผลระดับรายบุคคลเด็ดขาด" — นี่คือการตีความคำว่า "แบ่งหมวดหมู่ว่า
     แต่ละคนเป็นอย่างไร" ที่ปลอดภัย: แบ่งเป็นสัดส่วน/เปอร์เซ็นต์ของกลุ่ม ไม่ใช่ป้ายกำกับรายคน เพื่อไม่ให้
     เกิดการตีตราหรือเลือกปฏิบัติต่อพนักงานจากสุขภาพจิตของเขา

หมายเหตุสำคัญ
- ข้อมูลพนักงาน/แผนกทั้งหมดเป็นข้อมูลสุ่มจำลองเพื่อสาธิต ไม่ใช่ข้อมูลจริง
- การซื้อแบบรายบุคคลเป็นการจำลอง ยังไม่เชื่อมระบบชำระเงินจริง (ต้องต่อ Stripe/Omise/พร้อมเพย์ ฯลฯ)
- Prototype นี้ยังไม่มีระบบสมาชิกหรือ cloud database ข้อมูลทั้งหมดอยู่ใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น
- ก่อนเปิดใช้จริงควรเพิ่ม Privacy Policy, Consent, ระบบรักษาความปลอดภัย และช่องทางช่วยเหลือสุขภาพจิตที่เป็นทางการ
