JOBWAN 5.1 — Three separate login paths from the very first screen
======================================================================

วิธีใช้
1. แตกไฟล์ ZIP แล้วเปิด index.html
2. หน้าแรกที่เจอคือ "เลือกวิธีเข้าใช้งาน" มี 3 แท็บ: รายบุคคล / พนักงานองค์กร / HR ผู้ดูแลองค์กร

สิ่งที่เปลี่ยนในรอบนี้

หน้าแรกสุด (ก่อนนี้มีแค่ "ซื้อ" กับ "กรอกรหัสองค์กร" รวมกันหน้าเดียว) ตอนนี้แยกเป็น 3 แท็บชัดเจน:

1) 👤 รายบุคคล — ซื้อครั้งเดียว ฿129 (ปรับราคาจาก 59 เป็น 129 ตามที่ขอ) ใช้งานได้ตลอดไป

2) 🏢 พนักงานองค์กร — กรอกแค่ "รหัสองค์กร" รหัสเดียว เข้าใช้งานฟรีทันที (เหมือนเดิม)

3) 🔐 HR / ผู้ดูแลองค์กร — บัญชีแยกต่างหากโดยสิ้นเชิง กรอก "รหัสองค์กร + อีเมล + รหัสผ่าน" ล็อกอินแล้ว
   เข้าแดชบอร์ดสรุปผลองค์กรทันที ไม่ผ่านหน้าแรกของพนักงานเลย เพราะ HR ไม่ได้มาใช้ฟีเจอร์ไดอารี่/เช็กใจ
   ส่วนตัว แต่มาเพื่อดึงข้อมูลสรุปและดูแดชบอร์ดเท่านั้น
   - ระหว่างอยู่ในเซสชัน HR เมนูด้านข้างทั้งหมดจะซ่อนไป เหลือแต่แดชบอร์ด + ปุ่ม "ออกจากระบบ HR"
   - ถ้าล็อกอิน HR โดยที่เครื่องนี้ไม่เคยเป็นพนักงานขององค์กรนั้นมาก่อน การออกจากระบบ HR จะตัดการ
     เชื่อมต่อองค์กรทั้งหมดด้วย (กลับไปหน้าแรกสุด) เพราะบัญชีนั้นมีไว้เพื่อดูแดชบอร์ดเท่านั้น
   - แต่ถ้าเครื่องนี้เป็นพนักงานขององค์กรอยู่แล้ว (เข้าผ่านแท็บที่ 2 มาก่อน) แล้วค่อยกดดูแดชบอร์ด HR
     จากหน้าตั้งค่าทีหลัง การออกจากระบบ HR จะไม่ตัดสถานะพนักงาน ยังใช้แอปต่อได้ปกติ

ฟีเจอร์อื่นทั้งหมดเหมือนเดิมทุกอย่าง (ไดอารี่&จบวัน, พื้นที่ปล่อยใจ, เช็กใจ, ค้นหาความช่วยเหลือ, บทความ,
แดชบอร์ด HR แบบ 1,000 คนแยกตามแผนก, k-anonymity, จัดการลิงก์ EAP ฯลฯ)

หมายเหตุสำคัญ
- การล็อกอินทั้งหมดเป็นการจำลอง ยังไม่ตรวจสอบรหัสผ่าน/รหัสองค์กรกับเซิร์ฟเวอร์จริง
- Prototype นี้ยังไม่มีระบบสมาชิกหรือ cloud database ข้อมูลทั้งหมดอยู่ใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น
- ก่อนเปิดใช้จริงควรเพิ่ม Privacy Policy, Consent, ระบบรักษาความปลอดภัย และช่องทางช่วยเหลือสุขภาพจิตที่เป็นทางการ
