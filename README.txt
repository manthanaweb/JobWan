JOBWAN 3.0 — Merged Prototype (JobWan v2.1 + JOBWON)
=====================================================

วิธีใช้
1. แตกไฟล์ ZIP
2. เปิด index.html ด้วย Chrome / Edge / Safari
3. ข้อมูลถูกเก็บใน localStorage ของเบราว์เซอร์นี้เท่านั้น

ฟีเจอร์ทั้งหมด (รวมจากทั้งสองโปรเจกต์)
จาก JobWan v2.1 (คงไว้ทั้งหมด):
- Home, จบวันทำงาน (3 ขั้น: ค้างใจ / ทำสำเร็จ / แผนพรุ่งนี้), พื้นที่ปล่อยใจ (ชุมชนนิรนาม + กรองห้อง + ตรวจจับคำเสี่ยงสูง),
  เช็กใจ (สไลเดอร์ความเครียด + แนวโน้มรายสัปดาห์), ค้นหาความช่วยเหลือ, บทความ, ตั้งค่า/ความเป็นส่วนตัว, PWA ออฟไลน์

ใหม่จาก JOBWON ที่พอร์ตเข้ามา:
- ไดอารี่ (Diary): ปฏิทินรายเดือน + บันทึกประจำวัน (อารมณ์ 5 ระดับ, เรื่องราว, สิ่งที่ภูมิใจ, เรื่องค้างใจ, ความทรงจำดี ๆ,
  ข้อความถึงตัวเอง) แก้ไข/ลบย้อนหลังได้
- Mind Report ในหน้าไดอารี่: สรุปอารมณ์ตามสัปดาห์/เดือน/ปี, หัวข้อที่ปรากฏบ่อย, ข้อสังเกตเชิงรูปแบบ, สถิติ "My Year in Mind"
- Memory Jar: สุ่มเปิดความทรงจำดี ๆ ที่เคยบันทึกไว้ในไดอารี่
- Mind Check Point: สัญญาณไฟเขียว/เหลือง/ส้ม จากอารมณ์ไดอารี่ 14 วันล่าสุด
- Release Room: เขียนสิ่งที่อยากปล่อย แล้วเลือกวิธีปล่อย (เผา/ฉีก/ทะเล/หลุมดำ) พร้อมอนิเมชัน และบันทึกบทเรียนที่ได้

ฟีเจอร์จาก JOBWON ที่ยังไม่ได้พอร์ต (ตั้งใจ เพื่อไม่ให้ซ้ำซ้อนกับของเดิม)
- 1-Minute Shutdown แยกโหมด และ Full Shutdown + Brain Dump sorting — JobWan มีพิธีกรรมปิดวันทำงาน 3 ขั้นของตัวเองอยู่แล้ว
- Tomorrow Box แยกหน้า — overlaps กับ "แผนพรุ่งนี้" ในบันทึกปิดวันทำงานที่มีอยู่แล้ว

หมายเหตุ
- Prototype นี้ยังไม่มีระบบสมาชิกหรือ cloud database ข้อมูลทั้งหมดอยู่ใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น
- Mind Check Point และ Mind Report เป็น wellness signal จากข้อมูลที่ผู้ใช้บันทึกเอง ไม่ใช่การวินิจฉัยโรค
- ก่อนเปิดใช้จริงควรเพิ่ม Privacy Policy, Consent, ระบบรักษาความปลอดภัย และช่องทางช่วยเหลือสุขภาพจิตที่เป็นทางการ
